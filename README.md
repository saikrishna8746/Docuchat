DocuChat is a Retrieval-Augmented Generation (RAG) based document chatbot that allows users to ask questions about the content of PDF documents. The application uses LangChain to build the RAG pipeline, PyPDFLoader to extract content from PDFs, RecursiveCharacterTextSplitter to divide documents into manageable chunks, Hugging Face Sentence Transformers (all-MiniLM-L6-v2) to generate semantic embeddings, and Chroma as the vector database for storing and retrieving relevant document chunks. Google Gemini (gemini-3.6-flash) is used as the Large Language Model (LLM) to generate answers based on the retrieved context. The project demonstrates how document loading, text chunking, embeddings, vector search, retrieval, and LLM-based generation work together to build a practical AI-powered document question-answering system.
